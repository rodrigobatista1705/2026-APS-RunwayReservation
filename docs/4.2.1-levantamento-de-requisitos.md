# 4.2.1 Levantamento de Requisitos

## Como os requisitos foram levantados

Os requisitos do Runway Reservation foram levantados com três passos. Primeiro, uma **Entrevista** com o prof. Miguel, responsável pela pista e cliente do sistema, sobre como a utilização dos materiais funciona hoje. Depois, uma **Conversa** com Maria, uma professora que usa a pista semanalmente, e Wanessa, uma atleta que que usa os materiais para treinar. Por fim, a **Análise de um documento**: os termos de comprometimento que o prof Miguel pedia para assinar para o uso dos materiais ou da pista.

## Da fala à necessidade

| # | Fala | O que é | Necessidade por trás |
|---|---|---|---|
| F1 | "Eu queria um sistema com tela simples e objetiva para o acervo" (Prof Miguel) | solução | o usuário saber se o material ou pista estão disponível sem perguntar |
| F2 | "Toda vez eu tenho que perguntar para o Miguel se a pista está disponível" (Maria) | necessidade | consulta de disponibilidade feita pelo usuário |
| F3 | "Materiais que somem eu só descubro no inventário" (Prof Miguel) | **necessidade implícita:** não pediu, reclamou | saber onde está cada exemplar, a qualquer momento |
| F4 |  "Quando tenho que organizar uma aula diferente, preciso saber quais materiais já foram utilizados recentemente." (Maria) | necessidade | consultar o histórico de utilização dos materiais |
| F5 | "Seria bom conseguir acompanhar as utilizações anteriores para saber como a pista está sendo ocupada durante a semana." (Maria) | solução | consultar o histórico de utilização da pista |


## Histórias de usuário

| # | História de usuário | Veio de |
|---|---|---|
| HU01 |	Como professor, quero consultar a disponibilidade da pista e dos materiais, para saber se posso utilizá-los antes de planejar minha atividade. | F1, F8 |
| HU02 | Como responsável pela pisa, quero registrar um empréstimo e reserva de espaço, para saber quem está com cada material | F3, F4 |
| HU03 | Como atleta, quero registrar a devolução de um material, para que o sistema saiba que ele não está mais em minha posse. | F3, F6 |
| HU04 | Como responsável pela pista, quero cadastrar um material novo, para que ele possa ser encontrado no sistema | F4 | 
| HU05 | Como responsável pela pista, quero ver os empréstimos, para controlar quais estão em atraso e quais sumiram | F3 |



## Requisitos funcionais
| # | Nome | Requisito | Veio de |
|---|---|---|---|
| RF01 | Cadastrar Material | O sistema deve permitir que o responsável pela pista cadastre um material para utilização. | HU04 |
| RF02 | Cadastrar usuário | O sistema deve permitir que o responsável pela pista cadastre quem pode utilizar a pista | regra da pista: só pessoas com cadastro podem reservar ou emprestar materiais da pista |
| RF03 | Consultar disponibilidade | O sistema deve permitir o usuário consultar a disponibilidade da pista | HU01 |
| RF04 | Registrar empréstimo  | O sistema deve permitir que o responsável pela pista registre a reserva e empréstimo da pista e dos materiais | HU02 |
| RF05 | Registrar devolução | O sistema deve permitir que o usuário registre a devolução de materiais | HU03 |
| RF06 | Consultar histórico | O sistema deve permitir que o responsável pela pista e usuário consultem o histórico de empréstimos e reservas da pista | HU01 |
