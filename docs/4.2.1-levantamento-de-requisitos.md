# 4.2.1 Levantamento de Requisitos

## Como os requisitos foram levantados

Os requisitos do Runway Reservation foram levantados com três passos. Primeiro, uma **Entrevista** com o prof. Miguel, responsável pela pista e cliente do sistema, sobre como a utilização dos materiais funciona hoje. Depois, uma **Conversa** com Maria, uma professora que usa a pista semanalmente, e Wanessa, uma atleta que que usa os materiais para treinar. Por fim, a **Análise de um documento**: os termos de comprometimento que o prof Miguel pedia para assinar para o uso dos materiais ou da pista.

## Da fala à necessidade

| # | Fala | O que é | Necessidade por trás |
|---|---|---|---|
| F1 | "Eu queria um sistema com tela simples e objetiva para o acervo" (Prof Miguel) | solução | o usuário saber se o material ou pista estão disponível sem perguntar |

| F2 | "Toda vez eu tenho que perguntar para o Miguel se a pista está disponível" (Maria) | necessidade | consulta de disponibilidade feita pelo usuário |

| F3 | "Assino o termo e a vez esqueço e por o horário de entrega"(Wanessa) | necessidade |registro do empréstimo com horário da devolução feito pelo sistema |

| F4 | "Materiais que somem eu só descubro no inventário" (Prof Miguel) | **necessidade implícita:** não pediu, reclamou | saber onde está cada exemplar, a qualquer momento |

| F5 |  "Quando tenho que organizar uma aula diferente, preciso saber quais materiais já foram utilizados recentemente." (Maria) | necessidade | consultar o histórico de utilização dos materiais |

| F6 | "Se eu precisar sair antes do horário combinado, não sei como fica registrado o horário que devolvi o material." (Wanessa) | necessidade | registrar o horário efetivo de devolução dos materiais |

| F8 | "Seria bom conseguir acompanhar as utilizações anteriores para saber como a pista está sendo ocupada durante a semana." (Maria) | necessidade | consultar o histórico de utilização da pista |
